# 比較年表（日本・中国・世界）

日本史・中国史・世界史を横に並べ、「同じ時代、ほかの国では何が起きていたか」を一目で比べられる年表です。
HTML ファイル1つだけで動くので、インストールやサーバーは要りません。

## 概要

- **3つの地域を横並びで表示**：日本・中国・世界の時代区分と主な出来事を、同じ年代の行にそろえて並べています。範囲は旧石器時代から現代までです。
- **出来事をクリックすると解説が出る**：右側のパネルに、出来事の説明、その年の各地域の時代、前後の出来事が表示されます。
- **地域の表示を切り替えられる**：チェックボックスで、日本・中国・世界の列をそれぞれ表示したり隠したりできます。
- **交流・衝突を強調できる**：地域どうしの交流や衝突に関わる出来事には「交」の印が付いています。「交流・衝突だけ強調」にチェックを入れると、これらの出来事だけが目立つように表示されます。
- **年代へジャンプできる**：「古代」「0年」「500年」「1000年」「1500年」「1800年」「現代」のリンクで、その年代まで移動できます。
- **ダークモードに対応**：OS の設定に合わせて、明るい表示と暗い表示が自動で切り替わります。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `比較年表.html` | 年表の本体です。データ・デザイン・動きをすべてこの1ファイルにまとめています。 |

## ブラウザで開く手順

1. エクスプローラーで、このフォルダ（`AI練習`）を開きます。
2. `比較年表.html` をダブルクリックします。
   - 既定のブラウザ（Edge、Chrome など）で年表が開きます。
   - ほかのブラウザで開きたいときは、ファイルを右クリックして「プログラムから開く」を選び、ブラウザを選んでください。
3. 年表は縦横にスクロールして見られます。見たい出来事をクリックすると、解説パネルが開きます。
4. 解説パネルは「閉じる」ボタン、`Esc` キー、またはパネルの外側をクリックすると閉じます。

### コマンドで開く場合（PowerShell）

```powershell
Start-Process .\比較年表.html
```

## 注意

- 文字の書体（しっぽり明朝）は Google Fonts から読み込みます。インターネットにつながっていないときは、パソコンに入っている游明朝などで表示されます。年表の内容と機能はオフラインでもすべて使えます。
- 年代や出来事は学習用にまとめたものです。正確な年代や詳しい内容は、教科書や専門書で確認してください。
