# 200日線タッチ候補スクリーナー

東証（プライム・スタンダード・グロース）の全銘柄から、200日移動平均線にタッチしそうな銘柄を探すアプリです。

## 使い方

1. `run_app.bat` をダブルクリックすると、ブラウザで画面が開きます。
2. 左上の「株価データを更新」を押します（全銘柄の取得に5分ほどかかります）。
3. 一覧の行を選ぶと、チャートが表示されます。

## 判定方法

| 項目 | 計算方法 |
|---|---|
| 200日線 | 終値の単純移動平均（株式分割のみ調整、配当調整なし） |
| 距離（ATR） | 終値と200日線の差 ÷ ATR（直近14日の平均的な1日の値幅） |
| 乖離率 | （終値 − 200日線）÷ 200日線 |
| 接近中 | 直近5営業日で、終値と200日線の差が同じ側のまま縮まっている |
| 到達見込み | 現在の差 ÷ 直近5営業日の1日あたりの接近ペース |
| 当日タッチ済み | 当日の安値〜高値の範囲に200日線がある |

初期条件は「距離2ATR以内、乖離率5%以内、接近中、当日未タッチ、売買代金（20日平均）1億円以上」です。一覧は距離の近い順に並びます。到達見込みは直近のペースを延ばしただけの目安で、将来の値動きを予測するものではありません。

## 注意

- 株価は Yahoo Finance の非公式データ（`yfinance` 経由）です。遅延や欠損、仕様変更の可能性があります。
- 取引時間中に更新すると、途中の株価で計算されます。
- 売買が成立した日が200日に満たない銘柄は判定できないため除外されます（出来高0の日は数えません）。
- 直近220営業日に値幅制限で説明できない株価のギャップがある銘柄は、Yahoo 側の分割調整漏れの疑いがあるため除外し、画面に銘柄名を表示します。
